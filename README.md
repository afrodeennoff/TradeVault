## Mission

TradeVault is not a logging app. It is a **complete trader evolution system** that turns impulsive traders into disciplined, data-driven operators through:

- Professional trade tracking
- Deep behavioral psychology analysis
- Brutally honest AI coaching
- Visual replay & mistake playback
- Gamified discipline building
- Statistical edge detection

- **Tailwind CSS 4** + Framer Motion + Lucide
- **Pure analytics engine** (no black boxes)
- **React Hook Form + Zod** ready

## Getting Started (Zero Error)

```bash
git clone https://github.com/afrodeennoff/TradeVault.git
cd TradeVault
npm install
npm run dev
```

Open http://localhost:3000

Log trades. Watch the AI Coach destroy your bad habits. Export your journal. Level up.
